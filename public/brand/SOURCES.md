# ApexDevs official branding

Source: https://apexdevs.io/brand (retrieved 2026-10-01).

The brand page renders its wordmark with an inline SVG and Space Grotesk bold text; its PNG download is generated in-browser rather than served as a static file. This app preserves that light-theme component's SVG polygons, opacity, colors, font, weight, letter spacing, and icon spacing. Montserrat remains the interface font.

- `apexdevs-mark.svg`: exact SVG geometry from the official brand-page light wordmark.
- `space-grotesk-latin.woff2`: original font served by the brand page at `https://apexdevs.io/_next/static/media/0c89a48fa5027cee-s.p.0rd3rjvnnhw7n.woff2`.
- `/favicon-64.png`: https://apexdevs.io/favicon-64.png
- `/icon-192.png`: https://apexdevs.io/icon-192.png
- `/apple-touch-icon.png`: https://apexdevs.io/apple-touch-icon.png
